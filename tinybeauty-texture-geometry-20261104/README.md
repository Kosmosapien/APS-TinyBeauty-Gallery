# TinyBeauty: 512-pixel texture, geometry, and PatchGAN experiment
All previews are regenerated at native 512×512 from checkpoints and the source-mask composition. Style: V4 Social corrected by plane_iris_pixels, 1,000 train images, 32 held-out validation images, eight published examples. Frozen BeautyREC48 backbone trained for 20,000 updates. 512 refiners: 1,100 steps from scratch (texture-only, texture+local flow). PatchGAN ablation: start from the same 1,100-step texture-only checkpoint, 800 additional updates either with original loss or with adversarial 128×128 eye/lip patch discriminator. High-frequency amplitude ratio and pixel errors are validation diagnostics, not perceptual ranking. No mobile latency or production approval.
