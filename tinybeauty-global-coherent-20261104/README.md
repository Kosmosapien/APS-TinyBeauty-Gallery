# Global coherent makeup architecture ablation
Four independent scratch-trained 256² global U-Nets, 2 architectures x 2 full-image losses. Neither uses cosmetic subregion masks or makeup ROI losses. Global pyramid skip-only vs feature modulated decoder. Two losses: (1) L1+lowpass+gradient, (2) same plus image-global residual cosine-direction and magnitude. 1800 steps each, same 1000 train and 136 heldout IDs, no Albumentations. Comparisons with historical TinyBeauty24/BeautyREC48 at 20k are visual only, **not equal-training-budget benchmarks**. Research checkpoints, not production.
