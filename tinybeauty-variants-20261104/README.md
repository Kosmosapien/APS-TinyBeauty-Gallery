# TinyBeauty six variants / 2026-11-04

Live comparison of 12 validation identities, same V4 corrected teacher. Four controlled 2,500-step branches from the same BeautyREC 48-channel 20k checkpoint, two 5,000-step scratch width controls. All branch outputs are composited with source face mask. Experiments are exploratory; no Android benchmarking or production approval. Published metrics are recomputed on all 136 fixed validation images after the same mask compositing, matching the displayed examples; training variants have different total steps and must not be ranked as equal-budget architecture comparisons.
